# Character sprites

These intact 112×96 sheets are distributed by Pixel Agents:
https://github.com/pixel-agents-hq/pixel-agents/tree/main/webview-ui/public/assets/characters

Downloaded from the repository on 2026-10-24. Pixel Agents is MIT licensed;
the accompanying LICENSE.pixel-agents.txt preserves its notice.

Original character artwork: MetroCity by JIK-A-4, released under CC0:
https://jik-a-4.itch.io/metrocity-free-topdown-character-pack

Each sheet has three directional rows and seven 16×32 cells per row.
Office Hours draws these cells intact, mirrors the right-facing row for left,
and uses the seated registration described in Pixel Agents’ sprite renderer.
